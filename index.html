HOW TO INTERPRET RESULTS

Trip generation: estimates person trips from population and assumed trip rates.

Trip distribution: uses a simplified gravity impedance function to represent interactions between zones.

Mode choice: responds to assumed fare, service frequency, attractiveness and policy adjustments.

Traffic assignment: applies an iterative congestion feedback approximation. It is not a validated full Frank–Wolfe implementation.

Road geometry: the repository Major_Road.geojson and Minor_Road.geojson are displayed directly. Model link indicators are assigned to those mapped road features; the road geometry itself is never approximated by straight lines.

DATA & METHODOLOGY

Geography: The Gambia, using the repository road GeoJSON and Census_2024_2013.json where available.

Potential data sources for a calibrated model: GBoS Census_2024_2013.json EA population/household attributes and boundaries; validated household travel surveys; road centreline and condition inventory; traffic counts; GTFS or operator route and timetable data; terminal and stop locations; land-use and employment data.

Repository files: GAMBIA-TRANSPORT-NETWORK-SPATIAL-SIMULATION. Road and census layers are fetched from its main branch. Basemap tiles and raw GitHub data require internet access; model calculations run in this browser session.
